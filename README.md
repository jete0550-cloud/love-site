# Сайт для Кисы ❤️

Это готовый статический сайт для GitHub Pages.

## Файлы

- `index.html` — текст и структура сайта
- `style.css` — дизайн
- `script.js` — плавающие сердечки и просмотр фотографий
- `assets/` — фотографии

## Как опубликовать через GitHub Pages

1. Создай новый репозиторий на GitHub, например `love-site`.
2. Загрузи в него **все файлы и папку `assets`**.
3. Открой `Settings` → `Pages`.
4. В разделе `Build and deployment` выбери `Deploy from a branch`.
5. Выбери ветку `main` и папку `/ (root)`.
6. Нажми `Save`.
7. Через некоторое время GitHub покажет адрес сайта.
